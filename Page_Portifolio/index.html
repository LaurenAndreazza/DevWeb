Como se Conectar

Instruções e comandos para acessar o ambiente do servidor

Conexão Segura via Terminal (SSH)

Use o cliente SSH do seu sistema operacional para abrir uma sessão de terminal criptografada no servidor.

ssh admin@192.168.1.100 -p 2200
  • Certifique-se de que a sua chave SSH está autorizada no servidor.
  • Senha de acesso temporária enviada ao seu e-mail institucional.

Acesso Web (HTTP)

Acesse o servidor diretamente através do seu navegador para visualizar as aplicações web hospedadas.

http://192.168.1.100:8080
  • Verifique se o serviço web está ativo no painel de controle acima.
  • Porta padrão HTTP configurada é a 8080.

Transferência de Arquivos (SFTP/FTP)

Conecte-se usando clientes como FileZilla ou WinSCP para enviar e gerenciar arquivos do site.

sftp://192.168.1.100:2200
  • Usuário: admin
  • Caminho raiz: /var/www/html/page_portifolio
  • Utilize o protocolo seguro SFTP para transferências protegidas.
