Como se Conectar & Configurar

Instruções de conexão física, credenciais oficiais e tutoriais de acesso

Dados Oficiais do Seu Servidor

Estas são as credenciais que você configurou e que estão ativas agora na sua TV Box via cabo de rede:

IP Local (Ethernet) 192.168.15.6
Porta Web (Acesso HTTP) 8080
Link para acessar o site principal http://192.168.15.6:8080
Link para acessar o seu Vercel (Redirecionamento /sistema) http://192.168.15.6:8080/sistema
API de Conexão (Backend) http://192.168.15.6:5000
Porta SSH/SFTP (WinSCP) 8022
Caminho Raiz (Onde os arquivos ficam no Termux)
/data/data/com.termux/files/usr/share/apache2/default-site/htdocs/

Conexão Segura via Terminal (SSH)

Use o terminal de sua preferência para conectar-se remotamente ao Termux na TV Box.

ssh admin@192.168.15.6 -p 8022
  • Certifique-se de que a TV Box e o computador estejam na mesma rede local.
  • Use o comando passwd no Termux se precisar redefinir sua senha.

Acesso Web (HTTP)

Endereço do servidor para testar e ver suas aplicações pelo navegador na rede local.

http://192.168.15.6:8080
  • O servidor Apache2 hospeda o site principal na raiz do diretório.
  • Para acessar o painel do Vercel, use a subpasta /sistema.

API de Conexão (Backend)

Para se conectar ao servidor, o frontend do site deve se conectar por meio da API oficial:

http://192.168.15.6:5000
  • O frontend consome endpoints de dados e funções dinâmicas através deste endereço.
  • Certifique-se de configurar corretamente as variáveis de ambiente locais do seu projeto.

Guia Rápido: Como um aluno adiciona o site dele (Via WinSCP)

Para que seus alunos não sobrescrevam os projetos uns dos outros (e não apaguem o seu redirecionamento do /sistema), a melhor prática é que cada um tenha a sua própria pasta.

Passo 1: Abrir o WinSCP Abra o software WinSCP no computador de desenvolvimento.
Passo 2: Preencher os dados de conexão
  • Protocolo de Arquivo: SFTP
  • Host name: 192.168.15.6
  • Port parameter: 8022
  • User name / Password: (A senha que você criou quando rodou o comando passwd no Termux).
Passo 3: Navegar até a pasta raiz Na barra superior (ou pressionando Ctrl + O), cole o seguinte caminho raiz:
/data/data/com.termux/files/usr/share/apache2/default-site/htdocs/
Passo 4: Criar o diretório do projeto Clique com o botão direito em um espaço vazio na janela do servidor > Novo > Diretório. Dê o nome do seu projeto (ex: site-do-joao).
Passo 5: Enviar os arquivos Dê um duplo clique na nova pasta criada para entrar nela. Arraste todos os seus arquivos (index.html, style.css, etc.) do seu computador para dentro dessa pasta no WinSCP.
🌐 Como Acessar no Navegador Abra o navegador e digite o IP, a porta e a pasta do projeto. Exemplo:
http://192.168.15.6:8080/site-do-joao
